Publicar Peluquerías como aplicación

Dirección final: https://anibalrossia-spec.github.io/peluquerias/. Se instala en el celular y en la computadora. Usa la misma base de datos de Firebase que Socios Café (proyecto socio-cafe), en colecciones separadas, así que no hay que crear nada nuevo en Firebase.

Qué hay en esta carpeta

index.htmlLa aplicación.
config.jsConexión a Firebase (ya completo).
firestore.rulesReglas de seguridad para Socios Café y Peluquerías juntas.
manifest.webmanifest, sw.jsPara instalarla y que abra rápido.
icons/Íconos de la tijera.

Paso 1: publicar las reglas en Firebase

  1. Entrá a console.firebase.google.com → proyecto socio-cafe → Firestore → pestaña Reglas.
  2. Si arriba aparece "Ahora mismo · cambios sin publicar", las reglas ya están cargadas: tocá Publicar.
  3. Si no: borrá todo, abrí firestore.rules con el Bloc de notas, copiá todo, pegalo y tocá Publicar.
Estas reglas incluyen las de Socios Café sin cambios. No borres esa parte.

Paso 2: subir la aplicación a GitHub

  1. Entrá a github.com/new. Nombre: peluquerias. Public. Create repository.
  2. Tocá uploading an existing file, arrastrá todos los archivos de esta carpeta y la carpeta icons, y tocá Commit changes.
  3. Settings → Pages → Source: Deploy from a branch, rama main, carpeta / (root) → Save.
  4. En uno o dos minutos queda en https://anibalrossia-spec.github.io/peluquerias/.
El dominio anibalrossia-spec.github.io ya está autorizado en Firebase por Socios Café, así que no hace falta el paso de "Dominios autorizados". Si al crear la cuenta aparece un error de dominio, agregalo en Authentication → Configuración → Dominios autorizados.

Paso 3: primer uso

  1. Abrí la dirección → Soy peluquería → Crear la cuenta de mi peluquería.
  2. Revisá Servicios (vienen precios de ejemplo) y cargá tu equipo.
  3. En Agenda → Link para clientes copiá tu link y compartilo por WhatsApp o Instagram.
  4. Los clientes reservan solos desde ese link, sin crear cuenta. Los turnos aparecen al instante en tu agenda.

Para actualizar más adelante

En GitHub, repositorio peluquerias → Add file → Upload files → arrastrá el archivo nuevo → Commit changes.
